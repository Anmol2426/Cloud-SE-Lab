# Cloud-SE-Lab
📚 Library Management System
============================

A simple, responsive **Library Management System webpage** built using a single HTML file.

The webpage combines **HTML, CSS, and JavaScript** in index.html to create an interactive library dashboard.

<img width="1916" height="991" alt="image" src="https://github.com/user-attachments/assets/cc483331-f9bf-4bd8-88f3-05398c3bfacd" />


✨ Features
----------

*   📚 Library management dashboard
    
*   📊 Statistics for books and members
    
*   🔎 Search books by title, author, category, or book ID
    
*   🔍 Search results update while typing
    
*   🟢 Filter books by availability
    
*   🟠 Filter issued books
    
*   📖 View basic book details
    
*   🕒 Live date and time display
    
*   📱 Responsive design for smaller screens
    
*   🎨 Clean library-themed user interface
    

🛠️ Technologies Used
---------------------

*   HTML5
    
*   CSS3
    
*   JavaScript
    

No external libraries or frameworks are required.

🚀 How to Run
-------------

1.  Download or copy the index.html file.
    
2.  Save it in a folder.
    
3.  Open index.html in any modern web browser.
    

No server or installation is required.

🔎 Search Functionality
-----------------------

The search box allows users to search through the displayed books.

Search can be performed using:

*   Book ID
    
*   Book title
    
*   Author
    
*   Category
    
*   Status
    

The book table updates automatically as the user types.

🏷️ Book Filters
----------------

The webpage provides three filters:

*   **All** — Displays all books.
    
*   **Available** — Displays only available books.
    
*   **Issued** — Displays only issued books.
    

📖 Book Details
---------------

Clicking the **View** button on a book displays a small JavaScript alert containing:

*   Book title
    
*   Author
    
*   Category
    
*   Availability status
    

🕒 Live Date and Time
---------------------

The dashboard displays the current date and time.

JavaScript updates the displayed time every second.

📱 Responsive Design
--------------------

CSS media queries make the webpage adapt to different screen sizes, including:

*   Desktop
    
*   Laptop
    
*   Tablet
    
*   Mobile
    

📌 Important Note
-----------------

This is a **front-end webpage only**.

The book information is sample data stored directly in the HTML. The webpage does not currently have:

*   A database
    
*   User authentication
    
*   Permanent data storage
    
*   Real book issuing/returning
    
*   Real member management
    
*   Server-side functionality
